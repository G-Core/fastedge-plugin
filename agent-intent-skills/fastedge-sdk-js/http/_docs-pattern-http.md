# HTTP Example Docs Pattern Instructions

> For shared output format, cross-referencing rules, extraction rules, accuracy constraints, and exclusions see [_docs-pattern-base.md](../_docs-pattern-base.md)

This file adds HTTP-example-specific structure for docs pattern intent skills in the `http/` directory.

### Required sections (in this order)

1. **Overview** — 1-2 sentences: what this capability is and when to use it in FastEdge apps
2. **API Patterns** — key API calls with signatures, import paths, return types, and brief usage notes
3. **Common Patterns** — 2-3 short code snippets showing idiomatic usage of the capability
4. **Gotchas** — non-obvious constraints, limits, edge cases, or common mistakes
5. **Related** — cross-references to other reference topics using descriptive terms (see cross-referencing rules in base)
